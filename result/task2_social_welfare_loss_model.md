# 任务二：社会总福利损失函数模型

## 1. 模型目标

为刻画成品油价格调控机制下多方目标之间的权衡，构建社会总福利损失函数。模型以汽油、柴油两个品类为调控对象，在每个调价窗口选择调价释放比例，使消费者价格冲击、炼油企业压力、通胀压力、调价波动和能源安全风险的综合损失最小。

设油品类型为

```text
k ∈ {g, d}
```

其中 `g` 表示汽油，`d` 表示柴油。

## 2. 决策变量与价格动态

记第 `t` 个调价窗口中，任务一模型给出的理论调价幅度为

```text
f_{k,t}
```

实际调价幅度由调价释放比例决定：

```text
u_{k,t} = alpha_{k,t} f_{k,t}
```

其中

```text
0 <= alpha_{k,t} <= 1
```

`alpha_{k,t}` 越接近 1，表示越充分释放理论调价幅度；越接近 0，表示越强地平抑价格调整。

价格动态为：

```text
P_{k,t} = P_{k,t-1} + u_{k,t}
```

未释放的调价压力累积为：

```text
S_{k,t} = rho S_{k,t-1} + f_{k,t} - u_{k,t}
```

其中 `rho` 为压力衰减系数。

## 3. 社会总福利损失函数

总损失函数定义为：

```text
min J = sum_t (
    lambda_C  L^C_t
  + lambda_F  L^F_t
  + lambda_V  L^V_t
  + lambda_E  L^E_t
) + lambda_pi sum_m L^pi_m
```

权重满足：

```text
lambda_C + lambda_F + lambda_pi + lambda_V + lambda_E = 1
```

其中：

```text
L^C_t   消费者价格冲击损失
L^F_t   炼油企业压力损失
L^V_t   调价波动损失
L^E_t   能源安全损失
L^pi_m  CPI 通胀损失
```

## 4. 各项损失函数

### 4.1 消费者价格冲击损失

消费者主要承受价格上调带来的福利损失，因此只惩罚正向调价：

```text
L^C_t = sum_{k∈{g,d}} omega_{k,t}
        [ max(u_{k,t}, 0) / P_{k,t-1} ]^2
```

其中 `omega_{k,t}` 为汽油、柴油消费权重。

### 4.2 炼油企业压力损失

当理论调价未被充分释放时，成本或利润压力会累积。对正向压力进行惩罚：

```text
L^F_t = sum_{k∈{g,d}} omega_{k,t}
        [ max(S_{k,t}, 0) / B_k ]^2
```

其中 `B_k` 为企业压力归一化尺度。

### 4.3 CPI 通胀损失

先按月聚合汽柴油价格上调冲击：

```text
x_{g,m} = max(0, sum_{t∈T_m} u_{g,t} / P_{g,m-1})
```

```text
x_{d,m} = max(0, sum_{t∈T_m} u_{d,t} / P_{d,m-1})
```

构建 CPI 传导方程：

```text
pi_hat_{m+1} = beta_0 + beta_g x_{g,m} + beta_d x_{d,m} + beta_pi pi_m
```

通胀损失定义为：

```text
L^pi_m = [ max(0, pi_hat_{m+1} - pi_target) / sigma_pi ]^2
```

其中 `pi_target` 取 3%，`sigma_pi` 为历史 CPI 同比增速标准差。

### 4.4 调价波动损失

调价波动损失同时惩罚单次调价幅度和相邻调价变化：

```text
L^V_t = sum_{k∈{g,d}} omega_{k,t} [
    0.5 (u_{k,t} / U_k)^2
  + 0.5 ((u_{k,t} - u_{k,t-1}) / D_k)^2
]
```

其中：

```text
U_k = P90(|u^hist_{k,t}|)
D_k = P90(|u^hist_{k,t} - u^hist_{k,t-1}|)
```

### 4.5 能源安全损失

定义进口依赖度：

```text
d_t = Q^imp_t / (Q^prod_t + Q^imp_t)
```

定义国际油价高位压力：

```text
h_t = min(1, max(0, (Brent_t - 80) / (130 - 80)))
```

定义加工量不足压力：

```text
b_t = max(0, 1 - Q^process_t / MA12(Q^process_t))
```

定义国内价格压低程度：

```text
g_t = max(0, (P^*_t - P_t) / P^*_t)
```

其中 `P^*_t` 为理论价格，`P_t` 为实际价格。

能源安全压力递推为：

```text
A_t = max(0, rho_A A_{t-1} + theta_1 d_t h_t g_t + theta_2 b_t)
```

能源安全损失为：

```text
L^E_t = [ max(0, A_t - tau) ]^2
```

其中 `tau` 为历史能源安全压力的 75% 分位数。

## 6. 偏好权重参数

`lambda_C`、`lambda_F`、`lambda_pi`、`lambda_V`、`lambda_E` 属于政策偏好权重，不能仅由历史数据客观拟合。本文采用等权重方案作为基准，并设置多组偏好扰动方案进行敏感性分析。

### 6.1 基准权重

```text
lambda_C  = 0.20
lambda_F  = 0.20
lambda_pi = 0.20
lambda_V  = 0.20
lambda_E  = 0.20
```

### 6.2 敏感性分析权重方案

| 方案 | lambda_C | lambda_F | lambda_pi | lambda_V | lambda_E | 含义 |
|---|---:|---:|---:|---:|---:|---|
| equal_weight | 0.20 | 0.20 | 0.20 | 0.20 | 0.20 | 基准等权重 |
| consumer_priority | 0.40 | 0.15 | 0.15 | 0.15 | 0.15 | 更重视消费者价格稳定 |
| firm_priority | 0.15 | 0.40 | 0.15 | 0.15 | 0.15 | 更重视炼油企业压力缓释 |
| inflation_priority | 0.15 | 0.15 | 0.40 | 0.15 | 0.15 | 更重视 CPI 通胀控制 |
| volatility_priority | 0.15 | 0.15 | 0.15 | 0.40 | 0.15 | 更重视调价平滑 |
| energy_priority | 0.15 | 0.15 | 0.15 | 0.15 | 0.40 | 更重视能源安全 |

通过比较不同权重方案下的最优调价比例 `alpha_{g,t}`、`alpha_{d,t}` 和各类损失变化，可以检验模型结论对政策偏好的敏感性。

## 7. 最终优化问题

综上，任务二的优化模型可写为：

```text
min_{alpha_{g,t}, alpha_{d,t}} J
```

约束条件为：

```text
0 <= alpha_{g,t} <= 1
0 <= alpha_{d,t} <= 1
```

```text
u_{k,t} = alpha_{k,t} f_{k,t}
```

```text
P_{k,t} = P_{k,t-1} + u_{k,t}
```

```text
S_{k,t} = rho S_{k,t-1} + f_{k,t} - u_{k,t}
```

该模型在每个调价窗口中通过选择汽油、柴油的调价释放比例，实现消费者承受能力、炼油企业成本压力、宏观通胀稳定、调价平滑性和能源安全之间的综合权衡。
